# 语义基线发现

把当前源码、机器契约、测试和正式设计整理成一套可追踪的项目语义事实。只有用户显式触发或用户配置的外部定时任务才能进入全项目发现；无明确任务时等待。
任务调查读取允许路径与相关消费者，不以完整建库为前提。`inventory.py --path` 只输出局部报告与任务摘要，不写入全项目 Discovery。

## 预检

1. 调用 `semantic-contract` 取得对象和报告合同；报告阶段不要求先通过正式基线校验。
2. 读取项目指令、当前 Git 状态、已有 `.echo-semantic/`、design 和 ADR。
3. 搜索用户入口、后台入口、状态权威、持久化、外部副作用、失败恢复、公共契约和语义资产。
4. 分类全部 Git 路径；生成代码、第三方代码和排除路径仍必须有明确分类与复查条件。

## 用户确认后建模

扫描阶段先保存独立报告。实际用户确认候选与语义事实、并核对当前源码后才进入以下正式建模；扫描触发本身不授权更新基线。

1. 先建立候选事实底账，再按独立触发、状态权威、生命周期、副作用和裁决条件划分边界。
2. 每个中高风险能力建立 Capability Map，展开入口、结果、数据流、策略来源、失败路径和场景清单。
3. 为文件、符号、入口、状态权威、协议、测试消费者和文档建立 `asset` 对象；候选重复只记录线索。
4. Behavior 保存重要行为承诺，Rule 保存不变量和唯一权威，Evidence 只保存可复用证据。
5. 未知事实保持 `needs_review`，不得为了闭合而伪造行为或绝对安全结论。

需要独立探索时派发 `semantic-boundary-explorer`；需要能力闭合复核时派发
`semantic-capability-reviewer`。宿主没有专用角色时使用只读探索或审查能力，并传入完整路径、revision、范围和输出合同。

## 完成条件

- 当前源码摘要一致；
- 所有路径已分类且不存在冲突；
- 所有当前源码引用可以解析；历史引用能在对应 Git tree 中解析；
- 资产身份稳定，候选簇可追溯到源码和消费者；
- 库存闭合与行为模型闭合分别给出真实状态；
- 结构校验和严格快照校验通过。

完成后调用 `semantic-verify`。本 Skill 不修改业务代码。

## 独立报告与确认

全项目 `inventory.py --write` 只保存独立 `discovery.scan.<摘要>.md`，其 `scan_report` 嵌入资产、消费者线索、待确认候选、文件身份、排除项和未知项。没有 Baseline 也能保存；不写正式 assets/，不覆盖旧 Discovery、Baseline、Map、Behavior 或 Rule。只有显式需要长期候选报告时才用 `--write`；普通盘点输出和调试产物保存在 `.echo-semantic/local/<task-id>/` 或 CI Artifact。长期 Discovery 不意味着所有原始输出都应提交。

```bash
uv run scripts/inventory.py --root <仓库绝对路径> --write
uv run scripts/inventory.py --root <仓库绝对路径> --check-report <报告绝对路径>
uv run scripts/inventory.py --root <仓库绝对路径> \
  --confirm-report <报告绝对路径> --confirmation <用户明确答复的脱敏依据>
```

结构核对只证明报告合同，不要求源码仍匹配。实际用户确认候选和语义事实后才调用确认核对；它重扫源码，拒绝损坏、跨仓库或过期报告，输出匹配快照与下一入口，不修改基线。传入 confirmation 字符串不能证明用户授权。

确认核对后，调查候选的真实消费者、动态入口和行为证据，通过已有预检维护用户已确认的 Asset、Map、Behavior、Rule 和 Baseline，再运行全项目严格语义与工程验证。新项目先确认建库范围；业务修复、删除和提交分别授权。

扫描从一次内容快照提取线索，随后核对 HEAD、索引、路径集合和内容，保存锁内再次检查。已识别密钥路径、符号链接及大文件不读取内容；排除项保持覆盖缺口。单文件最多 8 MiB，总内容最多 128 MiB，报告最多 16 MiB；超限或中断不产生完整成功报告。长期报告可以提交，扫描不修改日常任务运行态。实际定时部署与真实触发验收由采用方用户配置后执行。

用户自行选择周期与外部执行环境时，参照[定时扫描接入与验收](../../docs/scheduled-scanning.md)。插件只提供调用入口和验收方法，不登记或启用实际定时任务。
