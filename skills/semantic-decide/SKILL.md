# 语义裁决

Agent 负责搜索和取证，人只处理证据无法替代的产品选择。每次只提出一个明确问题。

## 裁决单元

展示重要承诺、当前行为、已有期望或冲突、关键证据、受影响对象和唯一待决定问题。结果只能是：

- 确认期望；
- 修正期望；
- 接受明确残余风险；
- 暂缓并补充信息。

## 边界

- 不替人决定架构、兼容性、公共契约或是否删除能力。
- `risk_accepted` 必须保留人的明确裁决。
- 人确认的期望受保护；后续差异可以使实现失效，但不能自动改写该期望。
- 没有具体语义对象时不得创建裁决记录。

写回后调用 `semantic-verify`。若裁决要求改代码，回到正式设计、计划和构建流程，代码形成差异后调用
`semantic-diff`。
