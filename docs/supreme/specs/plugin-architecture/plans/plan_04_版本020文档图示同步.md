## Approach

在现有 0.2 语义整合实现上只同步版本源、发布文档和图示，不改变 Codex、Cursor、Claude Code 的事件合同或 Agent 投影。

## Global Constraints

- 所有版本源必须统一为 0.2.0。
- 文档图示必须反映 maintenance、Asset、候选 Finding、semantic-repair 和行为等价验证。
- 保持现有宿主适配字段、事件名称和 Agent 投影不变。

## Files

- Modify: `package.json` — 版本源。
- Modify: `.codex-plugin/plugin.json` — Codex 版本清单。
- Modify: `.cursor-plugin/plugin.json` — Cursor 版本清单。
- Modify: `.claude-plugin/plugin.json` — Claude Code 版本清单。
- Modify: `.claude-plugin/marketplace.json` — Marketplace 版本。
- Modify: `CHANGELOG.md`、`README.md`、`docs/releasing.md`、`docs/concepts.md` 和 `docs/host-support.md` — 发布文档。
- Modify: `docs/supreme/specs/plugin-architecture/design.md` — 架构流程图与时序图。

## Reuse

- `package.json`、三端 manifest、`scripts/validate-plugin.mjs` 和 `scripts/validate-package.mjs`：复用现有版本合同和分发校验。
